Does the app need an API key?+

Yes — one free Gemini API key from aistudio.google.com. Paste it once during setup and it is stored only on your device. Speech recognition, the wake word and the avatar all run locally.

Does it work without internet?+

Partly. Vosk speech recognition, the openWakeWord wake word and the echo cancellation run fully offline. Generating AI answers with Gemini needs an internet connection.

Which wake words are supported?+

Four on-device wake words: "Hey KMJ", "KMJ Jarvis", "KMJ" and "Hey Jarvis". Detection runs locally with ONNX models — audio never leaves your phone for wake detection.

Which APK should I download?+

Most people should pick the debug-full build — it bundles the wake-word models and everything works out of the box. The smaller release build is R8-minified and skips the wake-word models.

Which phones can install this APK?+

This release targets ARM64 Android phones running Android 10 or newer. It is not a 32-bit ARM or x86 build. The APK is signed with the KMJ JARVIS release key and distributed through GitHub releases.

Is it free and open source?+

Yes. KMJ JARVIS is GPLv3 open source, based on jarvis-android by h4harshill. The full source, build instructions and third-party notices are in the repository.

Can I build it myself?+

Absolutely. Clone the repo, open it in Android Studio, add your Gemini key when prompted and build. The README documents Gradle commands, signing and the project architecture.
